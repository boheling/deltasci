# Code of Conduct

DeltaScience is built for the AI4Science community. We want this project to be a welcoming place for researchers across career stages, disciplines, institutions, and backgrounds.

## Our standards

**Examples of behavior that contributes to a positive environment:**

- Using welcoming and inclusive language.
- Respecting different viewpoints and experiences, especially across disciplinary boundaries (a domain expert and an ML engineer often disagree productively — that's the whole point of this project).
- Giving and gracefully accepting constructive feedback.
- Focusing on what is best for the community.
- Showing empathy toward other community members, especially newcomers.

**Unacceptable behavior includes:**

- Harassment, insults, or discriminatory language.
- Personal or political attacks.
- Public or private harassment.
- Publishing others' private information without explicit permission.
- Other conduct that could reasonably be considered inappropriate in a professional setting.

## Scope

This Code of Conduct applies in all project spaces — issues, pull requests, discussions, mailing lists, social media when representing the project — and applies when an individual is officially representing the project in public spaces.

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers via a private GitHub message or a contact email listed in the repo. All complaints will be reviewed and investigated promptly and fairly.

Maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project leadership.
